# UI/UX спецификация

Сохранить утверждённый тёмный технотерминал, корпоративную сатиру, desktop-first сетку, фотореалистичные CGI стартапов и адаптивную мобильную версию.

## Путь игрока
Главная → правила → никнейм → случайный стартап → карточки раунда → результат → следующий раунд (до трёх) → финал → рейтинг. При обновлении открытая сессия и последний результат восстанавливаются с сервера.

## Экран раунда
Показывать прогресс, стартап и доступные публичные метрики. Основная область содержит ровно четыре карточки выбора: заголовок кратко называет приём атаки, описание объясняет конкретный сценарий. Совпадающую строку повествования не дублировать и не показывать два одинаковых текста разными цветами. На мобильном карточки идут одной колонкой; на широком экране допускается две. Поддержать клавиатурное управление, видимый фокус и понятное состояние выбранной кнопки.

После синхронного ответа показывать сюжетное событие и реакцию компании, защиту, финансовые изменения, обновлённые метрики и переход к следующему раунду. После refresh при `result_pending` восстановить сохранённый результат по `current_round_id`; отправка повторно не должна создавать новый ход.

Карточки v2 показывают игроку только публичный заголовок, описание и текст реакции. Скрытые коэффициенты, prerequisite, потери потоков и порядок выбора защиты остаются серверными. Если защита уже использована, интерфейс сообщает это в результате и не обещает повторную активацию.

## Состояния
`READY` — выбор карточки; `SUBMITTING` — временная блокировка до ответа API; `EVENT_REVEAL` → `DEFENSE_REVEAL` → `METRICS_REVEAL` — последовательная подача уже сохранённого результата; `NEXT_ROUND`; `GAME_OVER`; `ERROR_RETRYABLE`; `RESTORING`.

Любая анимация пропускается без потери данных. Учитывать `prefers-reduced-motion`, не включать звук автоматически и дублировать смысл сцен текстом. Повторная игра из завершённой сессии недоступна.

## Финалы и рейтинг
Финал показывает статус, счёт, компанию и ссылку на общий рейтинг. Четыре исхода описаны в `SCORING.md`. Ничьи получают одинаковое место. Рейтинг отображает только завершённые рейтинговые игры.

## Графика
Использовать утверждённые hero, responsive crops, thumbnail и браузерные сцены. Новые медиа во время игры не генерируются. Детали art direction — в `DESIGN_DECISIONS.md`, `ANIMATIONS.md`, `ASSETS.md`.
