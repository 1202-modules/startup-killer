# Повествование

Три выбранные карточки создают трёхактную историю: первый удар, реакция компании, последний ход. Тексты карточек и реакций заранее написаны и версионируются в `data/attack_choices.json`. Они задают подачу, но экономический исход всегда берётся из server engine.

Клиент использует утверждённые сцены `demand`, `reputation`, `competition`, `supply`, `technology`, `finance`, `pivot`, `absurd`; выбирает их карточка каталога. Существуют четыре детерминированных финала: `survived`, `deep_crisis`, `near_bankruptcy`, `bankrupt`. Не генерировать игровые тексты, стартапы, сцены или финансовые числа при runtime.
