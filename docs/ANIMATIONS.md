# Анимации и сториборд

Сохранить утверждённую подачу «кризисный терминал + анимированные сюжетные сцены». Движение только украшает серверный результат и не предсказывает его.

Восемь сцен `demand`, `reputation`, `competition`, `supply`, `technology`, `finance`, `pivot`, `absurd` реализуются браузерными CSS/SVG/Framer Motion слоями поверх существующего hero. Сцену задаёт заранее написанная карточка каталога. Четыре финала строятся браузером из метрик, графиков и общей иллюстрации.

Результат раунда приходит синхронно из API. Анимация может длиться несколько секунд, но всегда имеет «Показать сразу»; результат читаем без движения. Учитывать `prefers-reduced-motion`, не блокировать следующий шаг и не генерировать изображение/видео во время игры.

Статические CGI производятся только в разработке по `docs/ASSETS.md` и утверждённым prompts. Все сцены опираются на локальные ассеты.
