# Облегчённая архитектура

Production состоит из статической React SPA за Nginx, одного процесса FastAPI и PostgreSQL. Игра не вызывает внешние модели, не ставит jobs и не имеет worker/Redis. Один выбор вызывает локальный deterministic engine и атомарную транзакцию ledger.

Ориентир размещения — 2 vCPU / 2 GiB RAM; измерений целевого хоста здесь нет. Держать архитектуру простой: ограниченная пагинация рейтинга, индексы сессий/раундов/месяцев, отсутствие WebSocket и тяжёлой аналитики. Локальная производительность движка не заменяет реальный deployment benchmark.
