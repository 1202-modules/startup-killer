# Продуктовый контракт

«Убей стартап» — браузерная игра для очного мероприятия. Участник выбирает один из десяти вымышленных стартапов, случайно назначенных сервером, и за три раунда пытается причинить ему экономический ущерб. Партия занимает целевой интервал 5–7 минут, который необходимо подтверждать пользовательским замером. Сайт desktop-first с полноценной мобильной адаптацией.

## MVP
- Один никнейм и одна партия на установку браузера с мягкой cookie-ограниченной попыткой; нет регистрации и fingerprint.
- Ровно десять авторских паспортов в `data/startups.json`; сервер выбирает один случайно.
- Три раунда по три виртуальных месяца. На каждом раунде четыре заранее написанные карточки, подобранные для назначенного стартапа. Игрок выбирает одну.
- Все результаты и сюжетные тексты заранее записаны в каталоге. Runtime AI, свободный ввод атак, генерация карточек или повествования отсутствуют.
- Python-движок считает детерминированные эффекты, защиту, денежные потоки, банкротство, финалы и рейтинг.
- Один общий рейтинг завершённых рейтинговых партий. Нет редактирования стартапов или очков.
- Тёмный технотерминал и корпоративная сатира; статические стартап hero и браузерные анимации по утверждённой спецификации.

## Путь игрока
`/` → правила → никнейм → случайный стартап → раунд 1 → результат → раунд 2 → результат → раунд 3 либо раннее банкротство → финал → рейтинг.

## Вне MVP
«Инвестор», Telegram, мультиплеер, свободный текст, генеративный AI, создание компаний игроком, редактор коэффициентов/рейтинга, WebSocket и runtime generation медиа.

## Критерий качества
Сохранность сессий и точность экономики важнее декоративной анимации. Целевую скорость игры и production-ready статус нельзя утверждать без соответствующих реальных измерений.
