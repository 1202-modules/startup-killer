# Начало работы

Это действующий репозиторий браузерной игры «Убей стартап», а не пакет для генерации продукта с нуля. Исполняй утверждённые контракты и сохраняй текущие игровые правила, десять компаний, визуальную спецификацию и формулу экономики.

## Порядок
1. Прочитать `AGENTS.md`, `README.md`, `implementation/HANDOFF_GATES.md`, `implementation/CONFORMANCE_MATRIX.md`, `implementation/OPEN_DECISIONS.md`.
2. Выполнить `python3 tools/spec_check.py` и `python3 tools/contract_lint.py`.
3. Следовать `implementation/ROADMAP.md` и `implementation/TASKS.md`.
4. Перед изменениями экономики свериться с 30 oracle из `data/economy_golden_cases.json`.
5. После задачи обновить матрицу conformance только по реально полученным свидетельствам.

## Фиксированный игровой цикл
Случайный стартап из `data/startups.json`; три раунда по три месяца; четыре подготовленные карточки в раунде; запрос содержит только `choice_id`; расчёт проходит синхронно на сервере. Тексты, события и экономики во время партии не генерируются. Не добавлять провайдеры, AI worker, админ-панель, свободный ввод атаки или новые продуктовые роли.

Перед запуском `0002_deterministic_attack_choices` на существующей БД создать и проверить backup: миграция удаляет ключи и свободный текст; финансовая история завершённых ходов сохраняется, однако downgrade не поддержан. Не запускать production deployment или миграцию без отдельной задачи.

Визуальную спецификацию и правила работы со статическими ассетами см. в `docs/DESIGN_DECISIONS.md`, `docs/UI_UX.md`, `docs/ASSETS.md` и `assets/prompts/`. Любые статические изображения создаются только в разработке по утверждённому процессу; runtime image generation запрещена.
