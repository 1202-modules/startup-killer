# AGENTS.md — правила Startup Killer

## Обязательный порядок
Перед изменениями прочитать `ANTIGRAVITY_START_HERE.md`, `README.md`, `implementation/HANDOFF_GATES.md` и `implementation/CONFORMANCE_MATRIX.md`; выполнить `python3 tools/spec_check.py` и `python3 tools/contract_lint.py`. Продолжать работу только по `implementation/ROADMAP.md` и `implementation/TASKS.md`. При конфликте экономики остановить только затронутую часть и задать один точный вопрос владельцу.

## Продуктовый контракт
«Убей стартап» — браузерная desktop-first игра: один случайный из ровно десяти подготовленных стартапов, три раунда по три виртуальных месяца, общий рейтинг завершённых партий. В каждом раунде игрок выбирает один из четырёх заранее написанных вариантов из `data/attack_choices.json`. Новые тексты атак, выборы, экономика и повествование не генерируются во время игры. Никнейм, экономики, 10 паспортов, формула очков, ходов и визуальную спецификацию нельзя менять без решения владельца.

Каталог содержит публичные тексты и внутренние параметры исполнения. Клиент получает только ID, номер раунда, заголовок, краткое описание и текст атаки. Сервер проверяет выбор по снимку двенадцати карточек, закреплённому за сессией, применяет прежние валидаторы/движок экономики и формулу рейтинга. В браузер не передаются слабости, скрытые ID, коэффициенты и другие внутренние параметры.

## Стек и ограничения
React + TypeScript + Vite + Tailwind + Framer Motion + TanStack Query; Zustand — только локальный UI. FastAPI + SQLAlchemy 2 + Alembic + PostgreSQL. Production: статическая SPA через Nginx и один API-процесс. Без AI-провайдеров, AI worker, очередей, Redis/RQ/Celery, runtime-генерации медиа, Node SSR, Kubernetes и WebSocket. Ресурсный бюджет проекта: 2 vCPU / 2 GiB RAM; production готовность можно утверждать только после целевого host benchmark.

Существующие изображения и анимации остаются браузерными. Генерация статических ассетов в разработке допускается только по `assets/prompts/STYLE_MASTER.md`, `STARTUP_RENDERS.md` и `.agents/skills/produce-game-assets/SKILL.md`; это не игровая runtime-зависимость.

## Данные и безопасность
`data/startups.json`, `data/economy_golden_cases.json`, `data/attack_choices.json` и их схемы — нормативные входы. `docs/ECONOMY.md`, `docs/SCORING.md`, `docs/ENGINE_CONTRACT.md` определяют математику. Суммы остаются в копейках; рейтинг и расчёты выполняются только сервером. Не отдавать закрытые факты.

Миграция `0002_deterministic_attack_choices` удаляет AI/admin-таблицы, секреты и исходные тексты атак; сохраняет уже рассчитанные месячные проводки и результаты. Откат миграции намеренно запрещён, так как очищенные секреты и тексты восстановить нельзя. Перед миграцией существующей production-БД необходим проверенный резервный снимок.

## Проверки и отчёт
Использовать 30 `economy_golden_cases.json` как числовые oracle. AI/provider/live API проверки больше не являются частью проекта. Не запускать production-деплой или миграцию без отдельной задачи владельца. Не читать и не менять `.env`/локальные базы без необходимости. Не запускать безграничные проверки.

После завершения сообщить: задача → затронутые файлы → фактически выполненные команды и результаты → RSS/latency только если измерялись → отклонения → следующий этап. Документы и локальные тесты не считать доказательством production-ready.
