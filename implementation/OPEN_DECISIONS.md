# Открытые решения

В рамках утверждённой задачи продуктовых развилок нет. Зафиксировано: 4 заранее подготовленных варианта на каждый из 3 раундов каждого из 10 стартапов; запрос API содержит только `choice_id`; игрок видит только публичный текст карточки; экономика/рейтинг остаются прежними; runtime AI, свободный ввод, провайдеры и admin удалены.

Промежуточный v2 этап утверждён отдельно для PetMind, CoffeeBot, FoodRover и StudyGenie. Их explicit effects, новые защиты и границы `deep_crisis` заменяют соответствующие правила v1 только для новых сессий этих компаний. Числа из задания не корректировались. По `BALANCE_REPORT.md` остаётся решение владельца о коэффициентах и сопоставимости общего рейтинга; это не финальный баланс десяти компаний.

Операционные gates остаются незакрытыми: production миграция и host benchmark здесь не выполнялись. Downgrade миграции невозможен по смыслу, поскольку персональные данные и секреты очищаются; перед реальным запуском нужен проверенный backup и отдельная задача владельца.
