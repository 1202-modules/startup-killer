# Release runbook

## Перед выкладкой
1. Пройти локальные команды из `README.md` и acceptance matrix.
2. Для существующей БД создать внешний backup и проверить его восстановимость. Миграция `0002_deterministic_attack_choices` очищает прежний свободный текст и секреты; downgrade не поддержан.
3. Сверить актуальные environment-переменные из `.env.example`; не сохранять секреты в репозитории.
4. Провести bounded host benchmark на целевой конфигурации 2 vCPU/2 GiB и зафиксировать RSS/latency.
5. Проверить health route `/api/v1/health/live`, frontend и рейтинг в целевой среде.

## Rollback
Код можно вернуть по обычной процедуре релиза, но schema downgrade намеренно невозможен. Восстановление старого состояния требует восстановления проверенной резервной копии БД; учесть потерю всех изменений после снимка. Не запускать migration/restore без отдельной явной production задачи.

Локальная сборка не является production deploy acceptance.
