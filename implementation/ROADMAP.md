# ROADMAP

1. Предстарт: `AGENTS.md`, продуктовые контракты, `python3 tools/spec_check.py`, `python3 tools/contract_lint.py`.
2. Зафиксировать детерминированный набор 10 компаний и каталог 120 карточек (4 × 3 × 10); адаптер вызывает существующий экономический движок без изменения формул.
3. Сохранить версии и 12 выборов в сессии; реализовать атомарный API выбора, ledger и повтор результата.
4. UI: выбор карточки, синхронный результат и восстановление текущего результата после обновления.
5. Удалить runtime AI/admin/worker и старые инструкции/генераторы; миграция очищает персональные тексты, сохраняет resolved ledger.
6. Исчерпывающе пройти выборы по движку и обновить `BALANCE_REPORT.md`; выполнить локальные тесты/сборку и residual audit.
7. Production host benchmark, реальная миграция и визуальный acceptance — отдельные будущие gates; локальные результаты их не закрывают.

Поддерживай краткий отчёт по фактически затронутым файлам и реально запущенным командам. Не выдумывай продуктовые решения.
