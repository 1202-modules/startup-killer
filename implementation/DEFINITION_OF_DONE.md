# Definition of Done

- 10 заданных компаний и их baseline неизменны.
- Каталог валиден: ровно четыре выбора для каждой пары startup/round; внутренние параметры не уходят в публичный DTO.
- API принимает строго `choice_id`; повторные запросы не создают повторные ходы/проводки.
- Результаты совпадают с существующим экономическим движком и рейтингом; все месячные записи сохраняются.
- Завершённые финансовые ledger переживают очистительную миграцию; текст атак и runtime AI/admin таблицы удалены.
- Web UI позволяет выбрать карточку и восстановить синхронный результат.
- Balance report, локальные тесты, сборка и статические gates выполнены и точно указаны.
- Production host performance и deployment не называются проверенными без живого целевого запуска.
